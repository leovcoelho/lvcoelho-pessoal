02 · Colinha

COLINHA DE ENTREGA

Exemplos curtos para copiar, adaptar e transformar em entrega. O padrão é sempre o mesmo: pergunta de negócio, base limpa, modelo simples, métrica confiável, visual claro.

SQL · VENDAS POR MÊS

WITH vendas_mes AS (
  SELECT
    date_trunc('month', data_venda)::date AS mes,
    SUM(valor_total) AS receita,
    COUNT(DISTINCT id_pedido) AS pedidos
  FROM fato_vendas
  WHERE data_venda >= CURRENT_DATE - INTERVAL '12 months'
  GROUP BY 1
)
SELECT
  mes,
  receita,
  pedidos,
  receita / NULLIF(pedidos, 0) AS ticket_medio,
  receita - LAG(receita) OVER (ORDER BY mes) AS variacao_receita
FROM vendas_mes
ORDER BY mes;
Use para validar números antes de jogar no Power BI. Se o SQL e o dashboard divergem, investigue o modelo.

DAX · MEDIDAS BASE

Receita = SUM(Vendas[valor_total])

Pedidos = DISTINCTCOUNT(Vendas[id_pedido])

Ticket Medio = DIVIDE([Receita], [Pedidos])

Receita Mes Anterior =
CALCULATE(
  [Receita],
  DATEADD(Calendario[Data], -1, MONTH)
)

Crescimento MoM =
DIVIDE(
  [Receita] - [Receita Mes Anterior],
  [Receita Mes Anterior]
)
Essas 5 medidas resolvem boa parte de dashboard de vendas. Depois entram margem, meta e ranking.

PYTHON · ETL SIMPLES

import pandas as pd
from sqlalchemy import create_engine

vendas = pd.read_excel("vendas.xlsx")

vendas.columns = (
    vendas.columns
    .str.strip()
    .str.lower()
    .str.replace(" ", "_")
)

vendas["data_venda"] = pd.to_datetime(vendas["data_venda"])
vendas["valor_total"] = vendas["quantidade"] * vendas["preco_unitario"]

vendas = vendas.drop_duplicates(subset=["id_pedido", "produto"])
vendas = vendas[vendas["valor_total"] > 0]

engine = create_engine("postgresql+psycopg2://usuario:senha@host:5432/db")
vendas.to_sql("fato_vendas", engine, if_exists="replace", index=False)
Em cliente real, não deixe senha hardcoded. Use variável de ambiente ou arquivo .env fora do GitHub.

COMPORTAMENTO EM REUNIÃO

ANTES DA CALL

  • Pesquise o negócio: site, Instagram, Google Maps, setor

  • Prepare 6 perguntas, não uma apresentação de 30 slides

04 · Anti-commodity

COMO NÃO FICAR PRESO EM DASHBOARD

BI é porta de entrada. O teto maior está em dado confiável, integração, automação, governança e contexto de negócio. A tela fica barata; a fundação continua cara.

Tese central: não venda "faço dashboard". Venda "organizo dados financeiros e operacionais para a empresa fechar número, decidir melhor e preparar a base para BI e IA".

1 · DADOS + ERP + FINANCEIRO

Melhor ponte para dinheiro rápido, especialmente com a vantagem familiar em TOTVS/RM/contabilidade.

  • Extração de dados do ERP
  • DRE gerencial, conciliação, inadimplência e fechamento
  • BI financeiro para diretoria/controladoria
  • Menos glamour, mais dor real e orçamento

2 · ANALYTICS ENGINEERING

Você sai de "criador de tela" e vira quem constrói a camada confiável antes do dashboard.

  • SQL forte, modelagem, dbt, documentação
  • Camada semântica e métricas padronizadas
  • Qualidade de dados e lineage
  • Base mais segura para carreira corporativa em dados

3 · AUTOMAÇÃO COM IA

Use IA em fluxo real, não como promessa solta. O dinheiro está em automatizar trabalho repetitivo.

  • RAG com documentos internos
  • Agentes consultando base aprovada
  • Extração de nota, contrato, chamado e relatório
  • Exige API, segurança, avaliação e governança

4 · GOVERNANÇA & QUALIDADE

Quanto mais IA, maior a necessidade de saber se o dado é correto, permitido e auditável.

  • Dicionário de dados e dono de indicador
  • Regras de qualidade, validação e alerta
  • LGPD, permissão e dado sensível
  • Prepara empresas para BI, IA e auditoria

5 · RISCO, FRAUDE & SEGURANÇA

Dados aplicados a risco costumam pagar mais porque erro vira prejuízo direto.

  • Logs, anomalias, alertas e monitoramento
  • Fraude, crédito, cobrança e compliance
  • Ponte com cybersecurity e auditoria
  • Mais difícil, mas menos comoditizado

6 · REVOPS / FINOPS

Dados perto de receita e margem. Bom para projeto lateral porque o valor fica fácil de explicar.

  • Funil comercial, churn, comissão e forecast
  • Margem, CAC/LTV, cobrança e inadimplência
  • Automação de relatório gerencial
  • Venda consultiva mais forte que "dashboard bonito"

Python / ETL Automatiza coleta, limpeza, validação e carga de dados. Quando planilha manual vira gargalo ou quando há API/arquivos recorrentes. Script sem log, sem documentação e sem responsável vira bomba relógio.
ERP / financeiro básico Entender contas, centro de custo, nota, pedido, recebimento, estoque e fechamento. Para vender projetos que mexem com dinheiro e operação real. Virar consultor funcional puro se você não limitar o posicionamento.
Governança leve Define dono do dado, regra de qualidade, permissão e rotina de revisão. Antes de IA, retainer ou dashboard usado em decisão importante. Se virar burocracia grande no cliente pequeno, mata a venda.
IA aplicada RAG, agentes, extração de documentos e automação conectada a dados confiáveis. Depois de ter base limpa, caso de uso claro e risco controlado. Prometer IA antes da fundação de dados gera demo bonita e projeto morto.
Regra de evolução: comece com BI porque vende e gera case. Evolua para SQL + ERP/financeiro + automação + governança. Use IA como multiplicador depois que a base estiver confiável.

06 · Modelo

COMO O NEGÓCIO FUNCIONA

Sequência de produto — de onde vem a receita e como ela cresce.

01

ENTRADA VIA PROJETO ÚNICO

Ticket baixo (R$0–R$1.2k), escopo fechado, entrega rápida. Objetivo não é lucro — é gerar case, depoimento e relacionamento com o cliente.

  • Dashboard Starter ou Análise Pontual
  • Pro bono nos 2–3 primeiros
  • Sempre documentar resultado (antes/depois)
  • Pedir autorização para usar como portfólio
02

UPSELL PARA BI PRO / ETL

Depois de entregar o Starter com qualidade, o cliente naturalmente quer mais. Aí você apresenta o BI Pro ou Pipeline — projeto maior, ticket maior.

  • Ticket médio: R$2.000–3.500
  • Só faz sentido depois de ter o relacionamento
  • Taxa de conversão inicial: 10–20%; com nicho e cases fortes pode subir para 30%+
03

CONVERSÃO PARA RETAINER

A pergunta certa ao finalizar qualquer projeto: "Quem vai manter isso atualizado?" — A maioria das PMEs não tem resposta. Você oferece o Retainer BI.

  • MRR de R$800–1.500/mês por cliente
  • 2 clientes em retainer = R$1.600–3.000/mês estável
  • Combinar com emprego/estágio no início
04

ESCALA: MAIS CLIENTES OU MAIOR TICKET

Dois caminhos após validar o modelo. Não tente os dois ao mesmo tempo.

  • Mais clientes: volume, processo, template
  • Maior ticket: nicho específico, especialização, "Dados Under Control"
  • No ano 2+, avaliar contratar estagiário para parte operacional
Matematicamente: 3 clientes em retainer de R$1.200/mês + 1 projeto BI Pro/mês (R$2.500) = R$6.100/mês bruto. No remoto, trate isso como meta de 9–15 meses, não promessa de mês 6.

08 · Máquina

CAPTAÇÃO REMOTA SEM VIRAR SPAM

A meta é ser agressivo no processo, não genérico na mensagem. IA entra para pesquisar, pontuar, personalizar e acompanhar leads. Você entra para escolher, revisar e vender com contexto.

Princípio: para pegar os 10 primeiros clientes, não dependa de sorte. Rode uma máquina semanal: 100 leads pesquisados, 50–80 abordagens personalizadas, 2 follow-ups, CRM atualizado e revisão dos números todo domingo.

O QUE AUTOMATIZAR

  • Coleta de empresas em diretórios, Google, LinkedIn manual, Wellfound e comunidades
  • Classificação por nicho, tamanho, provável dor e fit com seus demos
  • Rascunho de mensagem com IA baseado no site/perfil da empresa
  • Follow-up, lembretes, status e métricas em planilha/CRM
  • Geração de variações de assunto, CTA e proposta

O QUE NÃO AUTOMATIZAR

  • LinkedIn auto-connect, auto-message ou scraping agressivo
  • Disparo igual para milhares de pessoas
  • Enviar e-mail sem opt-out ou sem identificação clara
  • Prometer diagnóstico sem olhar o negócio
  • Deixar IA falar por você sem revisão humana

STACK SIMPLES

  • Google Sheets/Airtable: CRM e pontuação de leads
  • Claude/GPT/Codex: pesquisa, personalização e objeções
  • Gmail/Workspace: envio controlado no começo
  • Calendly/Google Calendar: agendamento
  • Loom/YouTube privado: vídeo de demo ou análise rápida

CRM DE EXPERIMENTOS

Cada mensagem enviada vira dado. O objetivo não é só vender: é descobrir qual nicho, dor, canal, promessa e CTA geram resposta.

Item Como funciona Quando usar Risco
Campos obrigatórios Data, empresa, site, nicho, país, tamanho, decisor, canal, fonte do lead, score, dor provável e link da mensagem enviada. Antes de disparar qualquer abordagem. Sem registro, você só "acha" que um canal funciona.

Decisão semanal:

- Se teve proposta, mas não fechou: revisar preço, escopo ou urgência.
- Se fechou com margem boa: dobrar no nicho por mais 2 semanas.

10 · Execução

ROADMAP 90 DIAS

Do básico ao primeiro cliente pagante. Semana a semana — sem etapas em paralelo que não sejam necessárias.

Semanas 1–2 · AGORA
ARMAR O ARSENAL REMOTO
  • Construir 1 demo SaaS/e-commerce (MRR, churn, LTV, vendas, margem)
  • Construir 1 demo ERP/financeiro (DRE, inadimplência, centro de custo)
  • Subir demos no GitHub/portfólio com README, prints e vídeo curto
  • Reescrever LinkedIn para BI + SQL + automação + dados financeiros/operacionais
  • Criar planilha/CRM simples para registrar propostas, respostas e follow-ups
Semanas 3–4
DISTRIBUIÇÃO DIGITAL
  • Criar perfil no Upwork em inglês + 99Freelas/Workana em português
  • Enviar 50 propostas/abordagens personalizadas no total
  • Publicar 3 posts/semana no LinkedIn documentando demos e aprendizados
  • Entrar em 2 comunidades e responder 3 dúvidas úteis
  • Meta: gerar 3 conversas reais, mesmo sem fechar ainda
Semanas 5–6
PRIMEIRO CASE REMOTO
  • Fechar 1 projeto pro bono, barato ou microprojeto pago (US$50–300 / R$300–1.000)
  • Executar com IA como copiloto, mas validar números, código e escopo manualmente
  • Documentar antes/depois, arquitetura, limitações e decisão de negócio
  • Pedir review público, depoimento ou recomendação LinkedIn
  • Continuar: mais 50 propostas/abordagens
Semanas 7–8
TRANSFORMAR CASE EM PROVA
  • Publicar case no LinkedIn: problema → solução → resultado → lição
  • Atualizar portfólio com case real anonimizado
  • Fechar 2º projeto com preço maior (R$800–1.500 / US$150–500)
  • Testar 2 nichos remotos: e-commerce/SaaS e ERP/financeiro
  • Medir qual nicho responde melhor, não qual parece mais bonito
Semanas 9–10
RECORRÊNCIA E FILTRO
  • Oferecer manutenção mensal para todo projeto entregue
  • Meta: 1 retainer baixo (R$800–1.500/mês ou US$300–600/mês)
  • Criar pacote "Data Analyst as a Service" de 10h/mês
  • Recusar projeto sem acesso a dados, sem responsável ou sem escopo mínimo
  • Registrar como MEI/avaliar formalização se começar a faturar recorrente
Semanas 11–12 · Mês 3
AVALIAR E AJUSTAR
  • Revisar: canal, nicho, proposta, resposta, taxa de call e taxa de fechamento
  • Meta de renda: R$0–3.000; remoto pode demorar mais para decolar, mas tem teto maior
  • Escolher 1 nicho para dobrar nos próximos 90 dias
  • Definir próximos estudos: dbt básico, cloud trial e automação Python
  • Fazer revisão trimestral: cortar o que não respondeu e dobrar no que gerou conversa

O math de sustentabilidade: 2 retainers de R$1.500 + 1 projeto de R$3.000 = R$6.000/mês bruto. Para R$30k+, o modelo muda: tickets de R$5k–15k, retainers de R$3k–6k, clientes remotos melhores, ou emprego/contrato internacional.

MAPA 24 MESES / 5 ANOS

ANO 1 · PROVA

Meta: validar habilidade, canal e nicho sem abandonar a carreira corporativa.

  • 5–8 cases públicos ou anonimizados
  • 2–3 reviews em plataforma/LinkedIn
  • 1 nicho escolhido até mês 6–8
  • Renda lateral alvo: R$5k–12k no fim do ano

ANO 2 · TICKET

Meta: deixar de vender dashboard barato e vender solução de dados para um nicho.

  • Projetos de R$5k–10k
  • Retainers de R$2k–4k
  • Stack: dbt básico, cloud, SQL forte, automações
  • Testar cliente internacional ou PJ remoto melhor

ANOS 3–5 · 30K+

Meta: escolher uma rota de escala. Sem isso, o teto solo fica perto do tempo disponível.

  • Rota emprego: senior/lead/staff remoto ou contrato em USD
  • Rota consultoria: 4–8 retainers altos + freela/assistente
  • Rota produto: template, mini-curso, método ou automação vendável
  • Revisão trimestral obrigatória de canal, nicho, ticket e margem
→

ANO 2–3: DECISÃO BINÁRIA

Neste ponto você escolhe uma rota — não dá para fazer as duas bem:

  • Emprego internacional: construir stack (dbt, Airflow, AWS) e tentar mercado remoto em USD
  • Agência de dados: escalar a consultoria, contratar estagiário, ticket de R$5–10k/projeto
⚑

RISCO REAL: IA

Serviços de análise simples (EDA básico, limpeza de dados) estão sendo automatizados. O que protege:

  • Entender o negócio do cliente — IA não faz isso
  • Contexto setorial (varejo/agro/saúde)
  • Relacionamento e confiança com PME
  • Integração de sistemas legados
